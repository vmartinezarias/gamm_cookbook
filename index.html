Mastering the Non-Linear

Ecological data is rarely linear. Species response curves are often bell-shaped, growth is asymptotic, and spatial patterns are complex. GAMMs allow you to model these "wiggly" relationships while accounting for the random noise typical of field data (sites, years, blocks).

Cookbook Objective: This tool helps you select the right "ingredients" (distribution, link function), prepare your "utensils" (smoothers), and cook up a robust model code for R.

2. The Prep: Smoothers & Basis Functions

The s() function is the magic of a GAM. It fits a spline to the data. The 'wiggliness' is controlled by penalization, but you must set an upper limit on complexity using k (basis dimension).

4. The Taste Test: Validation

Never trust a model immediately. In ecology, checking for spatial/temporal autocorrelation and adequate wiggliness is mandatory.

🔍

Basis Dimension Check

gam.check(model)

Look at the p-value for k-index. If low (< 0.05), you might be undersmoothing. Increase `k` in your s() terms.

📈

Concurvity

concurvity(model)

The non-linear equivalent of collinearity. If values > 0.8, your smooth terms are confounding each other.

🗺️

Autocorrelation

acf(residuals(model))

If bars go outside the blue lines at lag 1, 2, etc., you need a correlation structure (e.g., AR1) in a gamm() call.

👁️

Visual Check

plot(model, pages=1)

Do the curves make biological sense? If a response curve oscillates wildly at the edges where data is scarce, constrain it!

5. Plating: Literature Example

Based on standard workflows in Zuur et al. (2009) & Wood (2017)

Scenario: Investigating the effect of Depth and Season on the abundance of a benthic fish species (Count data), while accounting for sampling Stations (Random Effect).

1. The Ingredients

  • • Response: Abundance (Count)
  • • Family: Negative Binomial (Overdispersion)
  • • Predictor 1: Depth (Continuous, Non-linear)
  • • Predictor 2: Season (Factor)
  • • Random Effect: Station (Intercept)

2. The Code

# We use 'negbin' family for overdispersed counts
# 'bs="re"' creates a random effect for StationID

final_model <- gam(Abundance ~ 
    s(Depth, k=5) +                # Smooth effect of depth
    Season +                       # Linear factor effect
    s(StationID, bs="re"),         # Random intercept for Station
    data = benthic_data,
    family = nb(),                 # Negative Binomial
    method = "REML")               # REML is preferred for smooths

summary(final_model)
plot(final_model, pages=1, all.terms=TRUE
Interpretation: The s(Depth) plot shows a hump-shaped curve, indicating preference for mid-depths. The random effect s(StationID, bs="re") captures the variance between stations that isn't explained by Depth or Season, preventing pseudoreplication.
