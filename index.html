Mastering the Non-Linear

Ecological data is rarely linear. Species response curves are often bell-shaped, growth is asymptotic, and spatial patterns are complex. GAMMs allow you to model these "wiggly" relationships while accounting for hierarchical structures (HGAMs).

Cookbook Objective: This tool helps you select the right "ingredients" (families like Tweedie/NegBin), prepare your "utensils" (smoothers & interactions), and cook up robust code.

4. Techniques: HGAMs & Interactions

Advanced structures for complex ecological questions (Pedersen et al. 2019).

Hierarchical GAMs (Grouping by Site)

Model G (Global) s(Time)

One curve for everyone.

Model H (Intercept) + s(Site, bs="re")

Same shape, different means (Random Intercept).

Model GS (Factor-Smooth) s(Time, Site, bs="fs")

Gold Standard. Each site has its own curve (Random Slope).

Interactions

Tensor Product te(x, z)

Use when variables have different units (e.g., Temp & Depth). Allows different wiggliness in each dimension.

Isotropic s(x, z)

Use for spatial coordinates (Easting, Northing) where units are the same.

5. The Cooking: Model Builder

Linear Effects

Simple regression terms. Use for parametric effects or simple controls.

Smooth Terms

"tp": Gold standard for continuous vars. Default.

"cc": Cyclic data (Months/Hours) where start meets end.

"cr": Cubic spline. Faster for massive datasets.

Random / HGAM

"re": Random Intercept. Account for group variation.

"fs": Factor Smooth. Separate smooth curve for every level of a factor.

6. The Taste Test: Validation

A GAMM is not complete without diagnostics. Use gam.check() and the gratia package.

🔍

Basis Check

gam.check(model)

If k-index < 1 and p < 0.05, the model is undersmoothed. Increase k!

📦

Visuals (Gratia)

appraise(model)

Produces a grid of 4 ggplot diagnostics (QQ, Residuals, Peakedness). Much better than base R.

📈

Concurvity

concurvity(model, full=F)

Non-linear collinearity. If values > 0.8, smooths are confounding each other.

🖼️

Partial Plots

draw(model)

Uses gratia to plot partial effects on the link scale with proper confidence intervals.

7. Plating: HGAM Example

Full recipe incorporating Hygiene, HGAMs, and Diagnostics.

Scenario: Effect of Depth and Temp on Fish Abundance (Overdispersed Counts), with seasonal trends varying by Site. 

# 1. Hygiene
df <- df %>% mutate(Site = as.factor(Site), Month = as.numeric(Month))

# 2. HGAM with Negative Binomial family
final_model <- gam(Abundance ~ 
    # Global seasonal trend (Cyclic)
    s(Month, bs = "cc", k = 12) + 
    
    # HGAM: Site-specific deviations (Factor-Smooth)
    s(Month, Site, bs = "fs", m = 2) + 
    
    # Interaction: Environment (Tensor Product)
    te(Temp, Depth, k = c(10, 10)) + 
    
    # Random Intercept for Year
    s(Year, bs = "re"),
    
    data = df,
    family = nb(),            # NegBin (learns theta)
    method = "REML",          # Unbiased selection
    knots = list(Month=c(1,12))) # For cyclic spline

# 3. Validation
appraise(final_model)         # Gratia diagnostics
gam.check(final_model)
